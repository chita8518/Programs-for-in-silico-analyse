# Programs-for-in-silico-analyse

Перед программной обработкой необходимо вручную сформировать таблицы данных:
1.	Импорт списка генов сигнального пути из KEGG
2.	Создание PPI-сети с этим списком генов веб-сервисом STRING со следующими настройками:
o	Network type:
	physical subnetwork
o	meaning of network edges: 
	confidence
o	active interaction sources:
	Experiments
	Databases
o	minimum required interaction score:
	high confidence (0.700)
o	network display mode:
	interactive svg
o	network display options:
	disable structure previews inside network bubbles
	hide disconnected nodes in the network
3.	Экспорт tsv таблицы PPI-сети в программный пакет Cytoscape как данные графа:
a.	вычисление топологических метрик встроенным инструментом Network Analyser
4.	Импорт функциональных аннотаций из PANTHER:
a.	импорт в формат txt, импорт в xlsx из txt
5.	Импорт xlsx таблицы функциональных аннотаций в Cytoscape как node table с назначением колонки gene name ключевой – именно по ней будет произведено объединение таблиц.
6.	Экспорт итоговой node table из Cytoscape в формате csv.
Алгоритм работы топологического фильтра:
1.	Импорт csv таблицы со значениями топологических метрик и функциональными аннотациями
2.	Сборка таблицы метрик со значениями из исходной csv таблицы
a.	'BetweennessCentrality',
b.	'Radiality',
c.	'Degree',
d.	'NeighborhoodConnectivity',
e.	'Stress', 
f.	'TopologicalCoefficient'
3.	Нормализация метрик:
a.	'BetweennessCentrality',
b.	'Degree',
c.	'NeighborhoodConnectivity',
d.	'Stress'
4.	Сравнение топологических метрик гена с квантилями, определенными эмпирически для сохранения специфичности фильтра (проверка шла на сетях WNT, NOD-NLR с использованием функциональных аннотаций как внутренний критерий корректности фильтра.)
5.	Формирование списка генов, прошедших квантили по не менее чем по четырем метрикам.
6.	Экспорт списка в формате txt.

Алгоритм работы экспрессионного фильтра:
1.	Импорт списка генов в формате txt
2.	Подключение к H5AD матрице scRNA-seq
3.	Импорт значений средней экспрессии и распространенности экспрессии
4.	Расчет индекса τ.
5.	Формирование Парето фронта генов по ожидаемой экспрессии и индексу τ 
6.	Экспорт таблиц экспрессии, txt списков групп генов по клеточной специфичности, txt списков Парето-оптимальных генов.

Эмпирический подбор порогов рассматривался не как способ подтверждения функциональной значимости генов, а как техническая процедура настройки специфичности предварительного топологического отбора.
